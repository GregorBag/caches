# Данные для тестирования кэша

Папка `cache-tests/` содержит 32 файла с последовательной нумерацией
`01`–`32`. В каждом первая строка — `1024` (размер пространства ключей),
вторая — `8192` (число запросов), затем 8192 целочисленных ключа
из диапазона `1..1024`, по одному на строку.
Вместимость кэша в файлах не задана.

Все данные синтетические. Проценты обозначают вероятность выбора, поэтому фактические доли могут
немного отличаться. Распределения описывают частоту обращения к ключам.
«Фон» означает независимый равномерный выбор из `1..1024`, если не указан
другой диапазон. Фон может случайно попасть и в горячий набор.

## Использование

Файлы содержат только трассу запросов; вместимости и стратегию кэша нужно
задавать отдельно в программе, читающей эти данные.

Для сравнения алгоритмов используйте одинаковые файлы и вместимости.
Значения 32, 64, 128, 256, 257, 512 и 1024 позволяют наблюдать разные
соотношения вместимости и рабочего набора. При вместимости 1024 все ключи
помещаются: для обычного кэша, сохраняющего загруженные ключи, число
попаданий равно 8192 минус число различных ключей в файле.
